POLY WEB — портфолио с Supabase Reviews

Откройте index.html через Live Server или разместите содержимое папки на GitHub Pages.
Отзывы сохраняются в Supabase и автоматически отображаются всем посетителям. Админка не требуется.

Внимание: публикация без модерации открыта для спама. Для публичного сайта желательно добавить CAPTCHA, ограничения частоты отправки и возможность удаления нежелательных отзывов в Supabase Table Editor.

Публичный ключ Supabase находится в assets/main.js. Никогда не добавляйте secret/service_role key в клиентский код.
